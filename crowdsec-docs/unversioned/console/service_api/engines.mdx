An `engine` exposes the informations related to Security Engines enrolled to your Organization.

### Get Engines

:::info
 - Refer to the [Security Engines](#security_engines) section for context.
:::

<Tabs
  defaultValue="curl"
  groupId="service-api-selection"
  values={[
    { label: 'cURL', value: 'curl' ,},
    { label: 'Python', value: 'python', },
  ]
}>
<TabItem value="curl">

```bash
curl -i -H "x-api-key: ${KEY}" -X GET -H "Content-Type: application/json" \
https://admin.api.crowdsec.net/v1/engines 
```

</TabItem>
<TabItem value="python">

```python
import os

KEY = os.getenv('KEY')

from crowdsec_service_api import (
    Engines,
    Server,
    ApiKeyAuth,
)
from httpx import HTTPStatusError

auth = ApiKeyAuth(api_key=KEY)

client = Engines(base_url=Server.production_server.value, auth=auth)
try:
    response = client.get_engines(
        tag=None,
        page=1,
        size=50,
    )
    print(response.model_dump_json())
except HTTPStatusError as e:
    print(f"An error occurred: {e.response.status_code} - {e.response.text}")
```

</TabItem>
</Tabs>

### Associate Tags With Engine

> Associate one or more tags with a Security Engine

<Tabs
  defaultValue="curl"
  groupId="service-api-selection"
  values={[
    { label: 'cURL', value: 'curl' ,},
    { label: 'Python', value: 'python', },
  ]
}>
<TabItem value="curl">

```bash
curl -i -H "x-api-key: ${KEY}" -X POST -H "Content-Type: application/json" \
https://admin.api.crowdsec.net/v1/engines/${ENGINE_ID}/tags \
-d '{ "tags": ["production", "eu-west"] }'
```

</TabItem>
<TabItem value="python">

```python
import os

KEY = os.getenv('KEY')
ENGINE_ID = os.getenv('ENGINE_ID')

from crowdsec_service_api import (
    Engines,
    Server,
    ApiKeyAuth,
)
from crowdsec_service_api.models import EngineAssociateTagsRequest
from httpx import HTTPStatusError

auth = ApiKeyAuth(api_key=KEY)

client = Engines(base_url=Server.production_server.value, auth=auth)
request = EngineAssociateTagsRequest(tags=["production", "eu-west"])
try:
    response = client.associate_tags_with_engine(engine_id=ENGINE_ID, request=request)
    print(response.model_dump_json())
except HTTPStatusError as e:
    print(f"An error occurred: {e.response.status_code} - {e.response.text}")
```

</TabItem>
</Tabs>

 - [Redoc method link](https://admin.api.dev.crowdsec.net/v1/docs#tag/Engines/operation/associateTagsWithEngine)

<details>
  <summary>answer on success (<code>201 Created</code>)</summary>

```json
{
  "modified_count": 1,
  "errors": {}
}
```

</details>


### Disassociate Tag From Engine

> Remove a tag from a Security Engine. The tag itself is not deleted, only its association with the engine.

<Tabs
  defaultValue="curl"
  groupId="service-api-selection"
  values={[
    { label: 'cURL', value: 'curl' ,},
    { label: 'Python', value: 'python', },
  ]
}>
<TabItem value="curl">

```bash
curl -i -H "x-api-key: ${KEY}" -X DELETE -H "Content-Type: application/json" \
https://admin.api.crowdsec.net/v1/engines/${ENGINE_ID}/tags/production
```

</TabItem>
<TabItem value="python">

```python
import os

KEY = os.getenv('KEY')
ENGINE_ID = os.getenv('ENGINE_ID')

from crowdsec_service_api import (
    Engines,
    Server,
    ApiKeyAuth,
)
from httpx import HTTPStatusError

auth = ApiKeyAuth(api_key=KEY)

client = Engines(base_url=Server.production_server.value, auth=auth)
try:
    client.disassociate_tags_with_engine(engine_id=ENGINE_ID, tag_name="production")
except HTTPStatusError as e:
    print(f"An error occurred: {e.response.status_code} - {e.response.text}")
```

</TabItem>
</Tabs>

 - [Redoc method link](https://admin.api.dev.crowdsec.net/v1/docs#tag/Engines/operation/disassociateTagsWithEngine)

:::info
On success the API returns `204 No Content` with an empty body.
:::
